# RiceUI API 卡片索引

> 生成：`node scripts/gen-api-cards.mjs --lib <uni_modules/rice-ui>`
> 官方站点：[riceui.cn](https://riceui.cn/)

共 **60** 个组件。写页面时先打开对应卡片，再打开「官方文档」链接核对示例。

生成时对照 [riceui.cn](https://riceui.cn/) 抓取 Props/Events；`rice-float-panel` 官方暂无独立文档页，卡片以源码为准。库升级后请重跑：

```bash
node .cursor/skills/rice-ui/scripts/gen-api-cards.mjs --lib <项目>/uni_modules/rice-ui
```
