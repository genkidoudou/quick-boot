# quickboot 对接积木报表 + JimuBI 指南

> 状态：文档与示例（**未改业务代码**）  
> 版本目标：`jimureport-spring-boot4-starter` / `jimubi-spring-boot4-starter` = **2.5.6.1**  
> 官方文档：[快速集成](https://help.jimureport.com/quick/) · [Releases](https://github.com/jeecgboot/jimureport/releases)

本文面向本仓库（Spring Boot **4.0.0** + Sa-Token + Vue3 quick-ui）。示例代码在 [examples/](./examples/)，类名带 `Example` / 文件名带 `.example`，复制时请改成正式包名并对照 **2.5.6.1 jar 接口** 微调。

---

## 1. 目标与非目标

### 1.1 目标

1. 同进程集成积木**报表**与**BI（大屏/仪表盘）**。  
2. 版本升到当前最新稳定补丁 **2.5.6.1**（含 API 数据集 302 绕过内网等安全修复）。  
3. 用 Sa-Token 登录态驱动积木鉴权（iframe `?token=` 可用）。  
4. 补齐前端已预留的目录 API：`/report/jimu/catalog/reports`、`/report/jimu/catalog/bi-pages`。  
5. 菜单可进入 `/jmreport/list`、`/drag/list`。

### 1.2 非目标（本阶段不做）

- JimuChatBI / `jeecg.jmreport.ai` / `autoTableEnabled`  
- magic-api  
- 把积木当业务 CRUD 替代  
- 多租户独立 schema（首期与业务共用 `quickboot-dev`）

## 2. 总体架构

```text
┌──────────────── quick-ui ────────────────┐
│  侧栏菜单（InnerLink / iframe）            │
│  IframeToggle 自动追加 ?token=Admin-Token │
└───────────────┬──────────────────────────┘
                │ /jmreport/list  /drag/list
                ▼
┌──────────────── quickboot-web ───────────┐
│ Sa-Token：notMatch 积木前缀（放行过滤器）   │
│ JmReportTokenServiceI：真正验票/角色/权限  │
│ IOnlDragExternalService：BI 字典/日志      │
│ JimuCatalogController：菜单绑目录          │
│ starter 自带 Controller + 前端静态资源     │
└───────────────┬──────────────────────────┘
                │ JDBC（主数据源）
                ▼
         MySQL quickboot-dev
    （业务表 + jimu_* / onl_drag_* 元数据表）
```

**安全模型（务必遵守）**

| 层 | 行为 |
|----|------|
| Sa-Token 拦截器 | 对 `/jmreport/**`、`/drag/**`、`/jimubi/**` **放行**（否则 iframe 空白） |
| `JmReportTokenServiceI` | **必须实现** `verifyToken`；失败则设计器进不去 |
| `getRoles` / `getPermissions` | 控制数据源、SQL 解析、删除等敏感按钮 |
| 生产 | 设计权只给超管/报表管理员，业务人员只看已挂菜单的预览页 |

## 4. 分步落地

### 步骤 A：升级版本并引入依赖

1. 父 POM properties：

```xml
<jimureport.version>2.5.6.1</jimureport.version>
<jimubi.version>2.5.6.1</jimubi.version>
```

2. `quickboot-web/pom.xml` 增加（完整注释见 [examples/pom-snippets.xml](./examples/pom-snippets.xml)）：

```xml
<dependency>
  <groupId>org.jeecgframework.jimureport</groupId>
  <artifactId>jimureport-spring-boot4-starter</artifactId>
</dependency>
<dependency>
  <groupId>org.jeecgframework.jimureport</groupId>
  <artifactId>jimubi-spring-boot4-starter</artifactId>
</dependency>
<dependency>
  <groupId>org.jeecgframework.jimureport</groupId>
  <artifactId>jimureport-echarts-starter</artifactId>
</dependency>
```

3. 验证：

```bash
cd quickboot
mvn -pl quickboot-web -am -DskipTests compile
```

报表与 BI **必须同版本族**，否则签名/验签容易失败（官方 2.5.4+ 起强调同源升级）。

### 步骤 B：初始化 SQL（Flyway）

1. 从官方文档下载：  
   - 报表：`jimureport.mysql5.7.create.sql`  
   - BI：官方「集成积木 BI」文档中的初始化脚本（与报表脚本配套的 2.5.6.1 版本）  
2. 建议拆成：  
   - `V26__jimureport_schema.sql`  
   - `V27__jimubi_schema.sql`  
   - （可选）`V28__jimureport_menu.sql` 菜单种子，示意见 [examples/V26__jimureport_menu.example.sql](./examples/V26__jimureport_menu.example.sql)  
3. 注意：  
   - 不要编辑已执行的 V1–V25  
   - 保持 `spring.flyway.placeholder-replacement: false`  
   - 脚本若含演示数据里的 `${...}`，禁止再打开 Flyway 占位符  

### 步骤 C：配置

合并 [examples/application-jimureport.yml](./examples/application-jimureport.yml) 中需要的键到 `application.yml`。

本阶段：

- **不要**配置 `jeecg.jmreport.ai`  
- 或显式保证 `autoTableEnabled: false`  

其它安全项（API 数据源 IP 校验等）按 [开发配置](https://help.jimureport.com/config/) 与 2.5.6.1 Release Note 打开。

### 步骤 D：Sa-Token 放行

修改 `SaTokenConfigure`，对积木前缀 `notMatch`。完整示例：

→ [examples/SaTokenConfigure.example.java](./examples/SaTokenConfigure.example.java)

关键代码形态：

```java
SaRouter.match("/**")
    .notMatch("/jmreport/**")
    .notMatch("/drag/**")
    .notMatch("/jimubi/**")
    // ... 你们原有登录白名单
    .check(StpUtil::checkLogin);
```

### 步骤 E：实现扩展接口（最重要）

#### E1. 报表：`JmReportTokenServiceI`

完整带注释示例：

→ [examples/JmReportTokenServiceImpl.example.java](./examples/JmReportTokenServiceImpl.example.java)

必须覆盖的能力：

| 方法 | 作用 |
|------|------|
| `getToken` | 从 Sa 上下文 / `?token=` / `X-Access-Token` / `Authorization` 取票，并 `StpUtil.setTokenValue` |
| `verifyToken` | `StpUtil.checkLogin()`，失败返回 false |
| `getUsername` | 返回登录账号 |
| `getRoles` | 超管 → `admin,lowdeveloper,dbadeveloper` |
| `getPermissions` | 超管 → 报表+BI 设计权限全集（示例里已列常用串） |
| `getDictList`（若接口存在） | 桥接 `SysDictApi.listByDictType` |

首期权限策略建议：

- 系统 `admin` / `*:*:*` → 积木设计全开  
- 其它用户 → 空角色空权限（或仅预览），避免任意人写 SQL 打业务库  

#### E2. BI：`IOnlDragExternalService`

完整带注释示例：

→ [examples/JimuDragExternalServiceImpl.example.java](./examples/JimuDragExternalServiceImpl.example.java)

首期：字典走 `SysDictApi`；`addLog` 打日志即可。

### 步骤 F：目录 API

前端已写死：

```js
// quick-ui/src/api/report/jimu.js
GET /report/jimu/catalog/reports
GET /report/jimu/catalog/bi-pages
```

后端示例（JdbcTemplate 读积木表，**表名落地前必须 DESC 核对**）：

→ [examples/JimuCatalogController.example.java](./examples/JimuCatalogController.example.java)

返回建议：`{ id, name, path }`，`path` 可直接给菜单 iframe。

### 步骤 G：菜单与前端

1. 增加目录「报表中心」。  
2. 菜单「报表设计」：系统内 iframe，`link=/jmreport/list`。  
3. 菜单「BI设计」：`link=/drag/list`。  
4. 依赖现有 `IframeToggle`：自动追加 `token`。  
5. `component` / `query` / `is_frame` 字段**以现网已成功的外链菜单为准**，示例 SQL 仅示意。  

菜单页若曾「裁剪积木/BI」选择器，可在目录 API 通后再恢复绑定 UI（非本阶段硬性）。

### 步骤 H：积木内权限文档

官方还有「集成积木权限」专章（角色注解 / 权限注解）。若设计器按钮 403：

1. 看浏览器网络面板缺少哪个 permission 字符串  
2. 补进 `getPermissions` 返回数组  
3. 不要图省事对所有登录用户返回 `*`（除非仅本地演示）

## 5. Token 时序（iframe）

```text
用户已登录 quick-ui（Cookie/本地存 Admin-Token）
        │
打开菜单 → IframeToggle 生成
  src = "/jmreport/list?token=" + encodeURIComponent(Admin-Token)
        │
浏览器请求积木 HTML/API
        │
Sa-Token 拦截器：路径命中 notMatch → 放行
        │
积木调用 JmReportTokenServiceI.getToken(request)
  → 读到 query token → StpUtil.setTokenValue(token)
        │
verifyToken → checkLogin 成功
        │
getRoles / getPermissions → 渲染设计器按钮
```

注意你们 `sa-token.token-prefix: Bearer`：Header 场景要剥前缀；query `token` 一般是**裸 token**（与 `getToken()` / Cookie 值一致）。示例代码已按此处理。

|---|--------|------|

## 7. 风险与排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| iframe 白屏 / 401 | 未放行路径 | 检查 `notMatch` |
| 进得去但按钮全灰 | `getPermissions` 为空或缺串 | 按 403 接口补权限 |
| 验签失败 | 报表/BI 版本不一致 | 统一 2.5.6.1 |
| SQL 被墙 | Druid wall | 确认 `select-where-alway-true-check: false` |
| Flyway 解析 `${` 失败 | 占位符开启 | `placeholder-replacement: false` |
| 字典为空 | 未实现 getDictList / BI 字典 | 接 `SysDictApi` |
| 编译找不到接口方法 | 示例与 jar 签名有差 | 以 2.5.6.1 源码/反编译为准改示例 |
