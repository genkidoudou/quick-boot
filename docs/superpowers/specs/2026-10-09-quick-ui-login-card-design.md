# Quick UI 登录页居中卡片改版设计

日期：2026-10-09  
状态：已落地到 `quick-ui/src/views/login.vue`（浅色科技玻璃）  
预览文件：`quick-ui/login-design-preview.html`

## 目标

将 `quick-ui` 登录页视觉对齐 MoviePilot 风格的「全屏氛围背景 + 居中半透明卡片」，同时保留现有全部登录能力。

## 已确认决策

| 项 | 选择 |
|----|------|
| 功能范围 | 保留账号 / 手机 / 扫码 Tab、记住密码、OAuth、天爱行为验证码 |
| 品牌 | 名称来自配置（如 `VITE_APP_TITLE` / 展示用品牌文案）；主色跟随 `--el-color-primary` |
| 背景 | 浅紫白雾面磨砂（模糊色块 + 噪点），不使用实景图；Logo 持续旋转 |
| 布局 | 方案 1：居中卡片 + 顶栏轻量分段 Tab |

## 视觉结构

1. **全屏背景**：浅紫白雾面磨砂（大色块径向渐变 + 强 `blur` + 极淡噪点），接近 MoviePilot 浅色登录底；可有缓慢光晕位移。
2. **居中卡片**：约 380px 宽，紧凑内边距（约 `32px 28px 18px`），圆角 16px；半透明白 + `backdrop-filter: blur(22px)`，柔和紫灰阴影。
3. **卡片头**：主色六边形 Logo（**持续慢速旋转**，约 12s/圈；尊重 `prefers-reduced-motion`）→ 大写品牌名 → 「欢迎登录」。
4. **Tab**：三段等分，选中态主色文字 + 短下划线。
5. **表单体**：输入框高度约 42px、间距紧凑；手机验证码按钮内嵌输入框右侧；OAuth 按钮同一行横排。
6. **卡片脚**：版权小号灰色，紧贴内容下方。

## 各登录方式

### 账号登录

- 用户名、密码输入框：圆角、左侧图标；密码可显示/隐藏。
- 「记住密码」勾选，勾选色为主色。
- 通栏主色「登录」按钮。
- 若有 OAuth 提供方：按钮下分割线「第三方登录」+ 描边按钮列表。

### 手机登录

- 手机号一行；验证码与「获取验证码」同一行（窄屏改为上下堆叠）。
- 主按钮样式与账号登录一致。

### 扫码登录

- 居中二维码区域 + 灰色说明文案。

### 行为验证码

- 保持现有全屏遮罩交互；遮罩容器圆角/阴影与卡片风格统一即可。

## 技术约束（实现阶段）

- 仅改 `login.vue`（及必要样式 token），不改登录 API / Store / 鉴权流程。
- 主色使用 `var(--el-color-primary)`（及衍生软色），避免写死紫色。
- 品牌展示文案与版权从现有 `appConfig` / 环境变量读取。
- 字体可继续使用现有 Manrope / Outfit。
- 响应式：≤480px 收紧内边距与 Tab 字号；矮屏避免版权遮挡卡片。

## 非目标

- 不引入实景背景图或外部图床依赖。
- 不删除手机 / 扫码 / OAuth / 验证码能力。
- 不在本设计中改动登录后的布局或主题系统其它页面。

## 验收标准

- 打开静态预览可切换三种登录方式，交互示意完整。
- 迁入 Vue 后：视觉接近预览稿；现有登录、短信、扫码占位、OAuth、验证码流程仍可用。
- 主题主色变更时，Logo 强调色、Tab 选中、勾选、主按钮同步变化。
