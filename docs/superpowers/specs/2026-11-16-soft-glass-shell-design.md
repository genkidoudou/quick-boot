# Soft Glass 产品壳设计

日期：2026-11-16  
范围：quick-ui 默认视觉气质升级（登录 / 工作台 / 全局壳层 + 列表换皮）  
状态：待实现计划

## 背景

quick-ui 已有 `DESIGN.md`、`--qb-*` 令牌、`glass` / `plain` 材质与主题包（主色预设）。登录页已有消费级氛围，但进入后台后仍偏传统管理台。目标是在**不破坏 C7 CRUD 约定**的前提下，把默认气质收成 Soft Glass：更像产品 App 壳，而不是若依式后台。

预览对照：

- `quick-ui/design-previews/consumer-styles.html` → 方案 1 Soft Glass App
- `quick-ui/design-previews/layout-b-vs-c.html` → 方案 B（换皮 + 壳层）

## 决策摘要

| 项 | 选择 |
|----|------|
| 覆盖面 | 对外面（登录/工作台）+ 整站气质 |
| 气质 | 消费级（MoviePilot / Apple 向），Soft Glass |
| 改动力度 | B：换皮 + 壳层；表格仍是表格 |
| 落地路径 | Token + 默认开关（不新建独立主题包） |
| 主色 | 默认仍 `#8D51F9`；主题包只换 primary |
| 字体 | 仍 Inter + Noto Sans SC |

## 目标

把 QuickBoot 默认气质收成 Soft Glass：消费级 App 壳 + 安静运维面。登录/工作台有温度；进列表后仍专业，但不像传统管理后台。

### 成功标准

- 打开应用第一眼像产品壳
- 任意 CRUD 页仍可完成「搜 → 表 → 弹窗」
- 玻璃浅（含壁纸）、玻璃深、平面浅、平面深四态可读、无隐字、无撞边、底栏不挡末卡
- 气质接近上述两份静态预览中的 Soft Glass + B

## 范围

### 做

- 全局令牌与材质：Soft Glass 为默认（玻璃默认开；圆角 / 阴影 / 侧栏顶栏微调）
- 壳层：侧栏、顶栏、工作台横幅与入口卡编排
- 登录品牌氛围与全局 `--qb-*` 对齐加强
- 列表面板外框（card / muted / 胶囊状态）换皮；`C7JsonTable` 交互不变
- 更新 `quick-ui/DESIGN.md`，写明 Soft Glass 为默认方向
- 保留 `design-previews/` 作为对照

### 不做

- 不新建 `soft-glass` 独立主题包
- 不把列表改成摘要卡 / 双栏详情（那是力度 C）
- 不换字体栈
- 不改主色默认值语义（主题包仍可切换 primary）
- 不改路由、菜单数据、权限、C7 列表/弹窗 API
- 不大改 Layout 信息架构（非方案 3）

## 令牌与材质

继续单一令牌源：`src/assets/styles/tokens.scss` → `--qb-*` → Element Plus / Tailwind。Soft Glass 是默认取值与开关，不是第二套灰阶。

### 色与表面

| 用途 | 浅色 | 深色 |
|------|------|------|
| 画布 `--qb-bg` | `#F2F2F7` | `#0B1322` |
| 卡片 `--qb-card` | 半透亮白玻璃 | 半透深海玻璃 |
| 次级座 `--qb-muted` | 静态吸收层（不二次 blur） | 同左 |
| 前景 / 次要 / 弱 | `#18181B` / `#52525B` / `#8E8E93` | `#F2F5FA` 及透明度档 |
| 主色 | `#8D51F9`（主题包可换） | 同左 |

### 材质默认

- 新用户 / 重置设置：**玻璃开**；壁纸可选；平面模式关壁纸（与现 `DESIGN.md` 一致）
- `backdrop-filter` 只在侧栏、顶栏、外层主卡片执行一次
- 表头工具条、嵌套面板只用 `muted` 静态吸收层
- 圆角：表面继续 `8 / 12 / 20 / 24 / 28`；壳层入口卡、横幅优先 `20–28`
- 浅色双层轻投影；深色少黑影，靠明度 + 细边框
- 边框继续 8% / 5% / 14% 三档；焦点唯一走 `--qb-ring`

### 业务约束

- 组件与页面只消费语义令牌，禁止硬编码灰阶
- 状态色只出现在可交互控件、选中态、需用户处理的信号

## 壳层与登录

### 侧栏

- 浅色默认：白 / 半透玻璃侧栏（非厚重深色条）
- 激活项：`primary-soft` 底 + 更深文字，不用高饱和色块整条刷满
- 分组标签用 `faint`
- 宽度与信息架构维持现网，只调材质与间距

### 顶栏

- 与侧栏同一玻璃表面；搜索 / 操作区更像产品工具条
- 主按钮用 primary；次要操作描边 / 浅底，避免一排实心色按钮

### 工作台首页

- 顶部品牌 / 氛围横幅（媒体或主色渐变 + `on-media` 文案）
- 下方入口用「品牌染色横幅卡」原型（上染色、下 `muted` 元信息）
- 可保留「最近活动」类面板，外框为 card，不是灰底表格岛

### 登录

- 保留现有氛围层；令牌与主色跟全局同步
- 登录卡：大圆角玻璃卡 + 单一主 CTA
- 品牌名是第一视觉，不堆后台说明书式文案

### 列表页（壳层视角）

- 可选薄横幅或页头说明（克制，不强制每页）
- 表格外层面板：`card` 外框 + `muted` 工具条
- 表内交互不变：搜 → 表 → `C7FormDialog`

## 落地文件（实现阶段指引）

1. 默认设置：玻璃默认开 — `theme.js` / 布局设置初始值 / store 默认
2. 令牌与几何：`tokens.scss`、`common.scss`、`themes/glass.scss`
3. 壳层组件：Layout / Sidebar / Navbar（或等价目录）
4. 工作台：`views/index.vue`（或工作台入口）
5. 登录：`views/login.vue`
6. 文档：`quick-ui/DESIGN.md`
7. 对照：`quick-ui/design-previews/`

具体路径以实现计划勘探为准；本 spec 约束「改什么、不改什么」，不绑定未核实的文件名之外的假设。

## 验收清单

- [ ] 桌面宽度与手机宽度各核验一遍
- [ ] 四态：玻璃浅（含壁纸）、玻璃深、平面浅、平面深
- [ ] 无文字隐身、无截断吞字、无圆角撞边
- [ ] 底部最后一张卡片不被悬浮栏遮挡
- [ ] 任意系统列表：搜 → 表 → 弹窗顺畅
- [ ] 对照 Soft Glass 预览 + B 布局预览气质一致

## 明确排除的替代方案

- **独立 soft-glass 主题包**：可回滚但长期双气质分叉；已否决
- **壳层信息架构重做**：超出 B 的成本与风险；已否决
- **列表 App 化（摘要卡 + 双栏）**：力度 C；本迭代不做
